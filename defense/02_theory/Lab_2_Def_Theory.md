# Защита лабораторной работы №2: Теоретические основы машинного обучения и нейронных сетей

Подробный разбор всех **20 теоретических вопросов** для сдачи и защиты лабораторной работы.

---

### 1. Задача классификации. Виды классификации. Рабочий процесс классификации.
* **Постановка задачи:** Обучение с учителем (Supervised Learning), где обучающая выборка состоит из пар $X = \{(\mathbf{x}_i, y_i)\}_{i=1}^N$, где $\mathbf{x}_i \in \mathbb{R}^d$ — вектор признаков, а $y_i \in Y$ — метка класса из конечного дискретного множества $Y = \{C_1, \dots, C_K\}$. Требуется построить решающую функцию $f: \mathbb{R}^d \to Y$, минимизирующую ожидаемую ошибку классификации.
* **Виды классификации:**
  1. *Бинарная (Binary):* два взаимоисключающих класса ($Y \in \{0, 1\}$).
  2. *Многоклассовая (Multiclass):* $K > 2$ классов, объект принадлежит строго одному классу ($Y \in \{1, 2, \dots, K\}$).
  3. *Многометочная (Multilabel):* объект может одновременно относиться к нескольким классам (вектор меток $y \in \{0, 1\}^K$).
* **Рабочий процесс (Workflow):**
  1. Сбор и аудит данных $\to$ 2. Предобработка (очистка, кодирование категорий, масштабирование) $\to$ 3. Разбиение на Train/Validation/Test $\to$ 4. Обучение моделей и подбор гиперпараметров $\to$ 5. Оценка качества по метрикам ($F_1$, $ROC\text{-}AUC$) $\to$ 6. Развертывание и мониторинг.

---

### 2. Логистическая регрессия (Logistic Regression).
* **Принцип:** Моделирует апостериорную вероятность принадлежности объекта к положительному классу через сигмоидную функцию от линейной комбинации признаков:
  $$P(y=1|\mathbf{x}) = \sigma(\mathbf{w}^T \mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w}^T \mathbf{x} + b)}}$$
* **Log-Odds (Логит):** Натуральный логарифм отношения шансов линеен по признакам:
  $$\ln\left(\frac{P}{1 - P}\right) = \mathbf{w}^T \mathbf{x} + b$$
* **Обучение:** Максимизация функции логарифмического правдоподобия (минимизация Log-Loss / Binary Cross-Entropy) с помощью градиентных методов (L-BFGS, Newton-Raphson, SGD).

---

### 3. Байесовский классификатор. Разновидности наивного байесовского классификатора.
* **Теорема Байеса:**
  $$P(C_k | \mathbf{x}) = \frac{P(C_k) \cdot P(\mathbf{x} | C_k)}{P(\mathbf{x})}$$
* **Гипотеза наивности:** Предполагается условная независимость признаков относительно класса: $P(\mathbf{x} | C_k) = \prod_{j=1}^d P(x_j | C_k)$.
* **Разновидности:**
  1. *GaussianNB:* для непрерывных величин $P(x_j|C_k) \sim \mathcal{N}(\mu_{kj}, \sigma_{kj}^2)$.
  2. *MultinomialNB:* для целочисленных счетчиков (тексты, bag-of-words).
  3. *ComplementNB:* адаптирован для несбалансированных выборок; параметры оцениваются по всем классам, кроме целевого.
  4. *BernoulliNB:* для бинарных булевых признаков ($x_j \in \{0, 1\}$).

---

### 4. Деревья решений для классификации. Принцип построения и критерии выбора разбиений.
* **Принцип построения:** Жадный рекурсивный алгоритм (CART / ID3 / C4.5), делящий пространство на гиперпараллелепипеды. На каждом шаге перебираются все признаки $j$ и все пороги $t$, выбирая предикат $[x_j \le t]$, максимизирующий прирост качества.
* **Критерии расщепления (Impurity):**
  1. *Индекс Джини (Gini Impurity):* $I_G(p) = 1 - \sum_{k=1}^K p_k^2$.
  2. *Энтропия Шеннона (Entropy):* $H(p) = -\sum_{k=1}^K p_k \log_2(p_k)$.
  3. *Прирост информации (Information Gain):* $IG(Q, j, t) = I(Q) - \frac{|Q_L|}{|Q|} I(Q_L) - \frac{|Q_R|}{|Q|} I(Q_R)$.

---

### 5. Линейный дискриминантный анализ (LDA).
* **Принцип:** Проекция данных размерности $d$ на подпространство меньшей размерности (для двух классов — на прямую $w$), максимизирующая критерий Фишера:
  $$J(\mathbf{w}) = \frac{\mathbf{w}^T S_B \mathbf{w}}{\mathbf{w}^T S_W \mathbf{w}} \to \max_{\mathbf{w}}$$
  * $S_B = (\mu_1 - \mu_0)(\mu_1 - \mu_0)^T$ — межклассовый разброс.
  * $S_W = \Sigma_0 + \Sigma_1$ — внутриклассовый разброс.
  * Оптимальное направление: $\mathbf{w} = S_W^{-1}(\mu_1 - \mu_0)$.
* **Предположения:** Данные в классах распределены нормально с одинаковыми ковариационными матрицами ($\Sigma_0 = \Sigma_1$).

---

### 6. Метод опорных векторов (Support Vector Machine - SVM).
* **Принцип:** Построение оптимальной разделяющей гиперплоскости $\mathbf{w}^T \mathbf{x} + b = 0$, обеспечивающей максимальный геометрический зазор (Margin) $M = \frac{2}{\|\mathbf{w}\|}$ между классами.
* **Опорные векторы:** Объекты обучающей выборки, лежащие на границе зазора или внутри него, удовлетворяющие $y_i(\mathbf{w}^T \mathbf{x}_i + b) \le 1$. Только они определяют веса $\mathbf{w}$.
* **Трюк с ядром (Kernel Trick):** Нелинейное отображение в пространство более высокой размерности через функции ядра $K(\mathbf{x}, \mathbf{z}) = \langle \phi(\mathbf{x}), \phi(\mathbf{z}) \rangle$:
  * RBF (Гауссово ядро): $K(\mathbf{x}, \mathbf{z}) = \exp(-\gamma \|\mathbf{x} - \mathbf{z}\|^2)$.

---

### 7. Метод ближайших соседей (k-NN).
* **Принцип:** Непараметрический ленивый алгоритм (Lazy Learner). Объект относится к тому классу, который преобладает среди его $k$ ближайших соседей в признаковом пространстве.
* **Метрики расстояния:**
  * Евклидово ($L_2$): $d(\mathbf{x}, \mathbf{z}) = \sqrt{\sum (x_j - z_j)^2}$.
  * Манхэттенское ($L_1$): $d(\mathbf{x}, \mathbf{z}) = \sum |x_j - z_j|$.
* **Взвешивание:** `weights='distance'` присваивает вес $w_i = \frac{1}{d(\mathbf{x}, \mathbf{x}_i)}$, нивелируя влияние далеких выбросов.

---

### 8. Ансамблевые алгоритмы (Ensemble Learning).
* **Концепция:** Объединение нескольких базовых моделей (слабых учеников) в одну мета-модель для снижения смещения (Bias) или дисперсии (Variance).
* **Основные парадигмы:**
  1. *Бэггинг (Bagging, Bootstrap Aggregating):* параллельное обучение независимых моделей на случайных подвыборках с возвращением (пример: **Random Forest**). Снижает дисперсию.
  2. *Бустинг (Boosting):* последовательное обучение, где каждая следующая модель компенсирует ошибки предыдущих (пример: **XGBoost, LightGBM, CatBoost**). Снижает смещение.
  3. *Стэкинг (Stacking):* мета-модель обучается на предсказаниях базовых алгоритмов.

---

### 9. Матрица ошибок классификации. Метрики качества.
* **Матрица ошибок (Confusion Matrix):** $TP$ (верно положительные), $TN$ (верно отрицательные), $FP$ (ложная тревога, ошибка I рода), $FN$ (пропуск цели, ошибка II рода).
* **Формулы метрик:**
  * $Accuracy = \frac{TP + TN}{TP + TN + FP + FN}$ (неприменима при сильном дисбалансе).
  * $Precision = \frac{TP}{TP + FP}$ (доля истинных среди предсказанных положительных).
  * $Recall = \frac{TP}{TP + FN}$ (доля найденных положительных объектов).
  * $F_1 = 2 \cdot \frac{Precision \cdot Recall}{Precision + Recall}$ (гармоническое среднее).

---

### 10. ROC-кривая, AUC-ROC и PR-кривая.
* **ROC-кривая:** График зависимости $TPR = Recall$ от $FPR = \frac{FP}{FP + TN}$ при варьировании порога отсечения $\theta \in [0, 1]$.
  * $AUC\text{-}ROC$ — площадь под кривой. $AUC = 0.5$ (случайный выбор), $AUC = 1.0$ (идеальная модель).
  * Устойчива к изменению баланса классов.
* **PR-кривая:** График зависимости $Precision$ от $Recall$. Незаменима при сильном дисбалансе (редкие события), где ROC-кривая может выглядеть оптимистично за счет огромного $TN$.

---

### 11. Оценка качества многоклассовой классификации (микро- и макроусреднение).
* **Макроусреднение (Macro-average):** Метрика ($Precision, Recall, F_1$) считается независимо для каждого класса $k$, затем берется простое арифметическое среднее:
  $$F_{1,\text{macro}} = \frac{1}{K} \sum_{k=1}^K F_{1,k}$$
  * Все классы равноправны (подчеркивает ошибки на малых редких классах).
* **Микроусреднение (Micro-average):** Сначала суммируются все $TP, FP, FN$ по всей выборке, затем считается единая метрика:
  $$Precision_{\text{micro}} = \frac{\sum TP_k}{\sum TP_k + \sum FP_k}$$
  * Эквивалентно общей Accuracy; доминируют крупные классы.

---

### 12. Дисбаланс классов. Влияние на обучение и оценку качества.
* **Влияние на обучение:** Алгоритм стремится минимизировать суммарную функцию потерь и вырождается в тривиальный константный прогноз мажоритарного класса.
* **Методы борьбы:**
  1. *На уровне данных:* Oversampling (дублирование редких строк, синтез SMOTE) или Undersampling (случайное удаление объектов большинства).
  2. *На уровне алгоритма:* Взвешивание функции потерь через параметр `class_weight='balanced'` ($w_k = \frac{N}{K \cdot N_k}$).

---

### 13. Биологический и искусственный нейрон.
* **Биологический нейрон:** Дендриты (входы) $\to$ Сома (тело клетки, суммация импульсов) $\to$ Аксон (передача потенциала действия) $\to$ Синапсы (связи с другими нейронами).
* **Искусственный нейрон Мак-Каллока-Питтса:**
  Вектор входов $\mathbf{x} = (x_1, \dots, x_m)$ умножается на синаптические веса $\mathbf{w}$, складывается со смещением (bias $b$) и проходит через нелинейную функцию активации $g$:
  $$y = g\left( \sum_{j=1}^m w_j x_j + b \right)$$

---

### 14. Однослойный и многослойный перцептрон (MLP).
* **Однослойный перцептрон Розенблатта:** Способен разделять только линейно разделимые образы (проблема исключающего ИЛИ, XOR-проблема Минского-Пейперта).
* **Многослойный перцептрон (MLP):** Состоит из входного слоя, одного или нескольких скрытых слоев и выходного слоя.
* **Теорема универсальной аппроксимации (Цыбенко, 1989):** Полносвязная нейросеть даже с одним скрытым слоем конечной ширины и нелинейной сигмоидной/ReLU активацией способна с любой наперед заданной точностью аппроксимировать любую непрерывную функцию многих переменных.

---

### 15. Прямое и обратное распространение сигнала (Backpropagation).
* **Прямой проход (Forward Pass):** Последовательное вычисление активаций от входного слоя к выходному:
  $$\mathbf{z}^{[l]} = W^{[l]} \mathbf{a}^{[l-1]} + \mathbf{b}^{[l]}, \quad \mathbf{a}^{[l]} = g^{[l]}(\mathbf{z}^{[l]})$$
* **Обратное распространение ошибки (Backpropagation):**
  Применение цепного правила дифференцирования (Chain Rule) для вычисления частных производных градиента функции потерь по весам всех слоев:
  $$\delta^{[l]} = \frac{\partial \mathcal{L}}{\partial \mathbf{z}^{[l]}} = \left( (W^{[l+1]})^T \delta^{[l+1]} \right) \odot g'(\mathbf{z}^{[l]})$$
  $$\frac{\partial \mathcal{L}}{\partial W^{[l]}} = \delta^{[l]} (\mathbf{a}^{[l-1]})^T, \quad \frac{\partial \mathcal{L}}{\partial \mathbf{b}^{[l]}} = \delta^{[l]}$$

---

### 16. Классификация и виды нейронных сетей.
1. **Полносвязные (Feedforward / MLP):** Обработка структурированных табличных данных.
2. **Сверточные (CNN):** Архитектуры с ядрами свертки и пулингом для изображений и пространственных данных.
3. **Рекуррентные (RNN, LSTM, GRU):** Обработка последовательностей и временных рядов с внутренним состоянием памяти.
4. **Трансформеры (Transformers):** Механизм внимания (Self-Attention) для текстов (LLM) и мультимодальных задач.

---

### 17. Функции активации нейронных сетей. Назначение и основные виды.
* **Назначение:** Внесение нелинейности. Без них многослойная сеть сворачивается в простую линейную модель $W_2(W_1 x) = W_{new} x$.
* **Основные виды:**
  1. *Сигмоида:* $\sigma(z) = \frac{1}{1 + e^{-z}} \in (0, 1)$. При $|z| > 5$ страдает от затухания градиента ($Vanishing\\,Gradient$).
  2. *Гиперболический тангенс:* $\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}} \in (-1, 1)$. Центрирован вокруг 0.
  3. *$ReLU$ (Rectified Linear Unit):* $f(z) = \max(0, z)$. Быстро вычисляется, градиент равен 1 при $z > 0$, не затухает. Проблема: отмирание нейронов (Dying ReLU).
  4. *Leaky ReLU / ELU:* $f(z) = z$ при $z \ge 0$ и $\alpha z$ при $z < 0$. Устраняет проблему зануления отрицательных градиентов.
  5. *Softmax:* Многоклассовое обобщение сигмоиды для выхода: $p_k = \frac{e^{z_k}}{\sum_j e^{z_j}}$.

---

### 18. Функции потерь нейронных сетей (Loss Functions).
* **Назначение:** Количественная мера штрафа за несовпадение прогноза модели с истинной меткой.
* **Основные виды:**
  1. *Binary Cross-Entropy (бинарная кросс-энтропия):*
     $$\mathcal{L}_{BCE} = -\frac{1}{N} \sum_{i=1}^N \left[ y_i \ln(\hat{y}_i) + (1 - y_i) \ln(1 - \hat{y}_i) \right]$$
  2. *Categorical Cross-Entropy (многоклассовая):* $\mathcal{L} = -\sum_{k=1}^K y_k \ln(\hat{y}_k)$.
  3. *Mean Squared Error (MSE / регрессия):* $\mathcal{L} = \frac{1}{N} \sum (y_i - \hat{y}_i)^2$.

---

### 19. Методы оптимизации в нейронных сетях.
* **Градиентный спуск (GD / SGD):** Обновление весов в сторону антиградиента $\theta_{t+1} = \theta_t - \eta \nabla \mathcal{L}(\theta)$.
* **Улучшенные оптимизаторы:**
  1. *Momentum:* Добавление экспоненциального скользящего среднего прошлых градиентов (эффект инерции для преодоления локальных минимумов).
  2. *RMSProp:* Адаптивная нормализация скорости обучения делением на корень из скользящего среднего квадратов градиентов.
  3. *Adam (Adaptive Moment Estimation):* Комбинация Momentum (1-й момент $m_t$) и RMSProp (2-й момент $v_t$):
     $$\theta_{t+1} = \theta_t - \frac{\eta}{\sqrt{\hat{v}_t} + \epsilon} \hat{m}_t$$

---

### 20. Типы обучения нейронной сети. Процесс обучения.
* **Типы обучения:**
  1. *Обучение с учителем (Supervised):* обучение на парах $(X, y)$.
  2. *Обучение без учителя (Unsupervised):* поиск скрытых структур (кластеризация, автоэнкодеры).
  3. *Обучение с подкреплением (Reinforcement Learning):* оптимизация политики агента через награды среды.
* **Процесс обучения (Training Loop):**
  1. Выборка делится на мини-батчи (Batch size, например 32).
  2. Прямой проход (Forward pass) $\to$ получение предсказаний $\hat{y}$.
  3. Расчет значения функции потерь $\mathcal{L}(\hat{y}, y)$.
  4. Обратный проход (Backprop) $\to$ расчет градиентов $\nabla_\theta \mathcal{L}$.
  5. Шаг оптимизатора (Optimizer step) $\to$ обновление весов $\theta \leftarrow \theta - \Delta \theta$.
  6. Проверка метрик на валидационном множестве в конце эпохи (Epoch end).
