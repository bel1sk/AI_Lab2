## ✍️ Задача 1. Расчет метрик по заданной матрице ошибок (Confusion Matrix)

### Условие:
Преподаватель рисует на доске матрицу ошибок:
| | Предсказано: 0 | Предсказано: 1 |
|---|:---:|:---:|
| **Истинно: 0** | **$TN = 1500$** | **$FP = 50$** |
| **Истинно: 1** | **$FN = 150$** | **$TP = 300$** |

### Решение:
1. **Общий размер выборки ($N$):**
   $$N = 1500 + 50 + 150 + 300 = 2000$$
2. **$Accuracy$ (Общая точность):**
   $$Accuracy = \frac{TP + TN}{N} = \frac{300 + 1500}{2000} = \frac{1800}{2000} = 0.90 \quad (90.0\%)$$
3. **$Precision$ (Точность):**
   $$Precision = \frac{TP}{TP + FP} = \frac{300}{300 + 50} = \frac{300}{350} \approx 0.8571 \quad (85.71\%)$$
4. **$Recall$ (Полнота):**
   $$Recall = \frac{TP}{TP + FN} = \frac{300}{300 + 150} = \frac{300}{450} \approx 0.6667 \quad (66.67\%)$$
5. **$F_1\text{-Score}$ (Гармоническое среднее):**
   $$F_1 = 2 \cdot \frac{Precision \cdot Recall}{Precision + Recall} = 2 \cdot \frac{0.8571 \cdot 0.6667}{0.8571 + 0.6667} = \frac{1.1428}{1.5238} \approx 0.7500 \quad (75.0\%)$$

## ✍️ Задача 2. Расчет критерия Джини (Gini Impurity) для узла дерева решений

### Условие:
В родительском узле находится $100$ объектов: $80$ класса 0 и $20$ класса 1.  
Признак $x$ разбивает узел на:
* Левый дочерний узел ($Q_L$): $40$ объектов класса 0 и $0$ объектов класса 1 (всего $40$).
* Правый дочерний узел ($Q_R$): $40$ объектов класса 0 и $20$ объектов класса 1 (всего $60$).
Определить, уменьшилась ли неоднородность и каков прирост информации ($IG$).

### Решение:
1. **Джини родительского узла ($Q$):**
   $$p_0 = \frac{80}{100} = 0.8, \quad p_1 = \frac{20}{100} = 0.2$$
   $$I_G(Q) = 1 - (p_0^2 + p_1^2) = 1 - (0.64 + 0.04) = 1 - 0.68 = 0.32$$
2. **Джини левого узла ($Q_L$):**
   Узел идеально чистый ($p_0 = 1.0, p_1 = 0$):
   $$I_G(Q_L) = 1 - (1.0^2 + 0^2) = 0.0$$
3. **Джини правого узла ($Q_R$):**
   $$p_0 = \frac{40}{60} = \frac{2}{3}, \quad p_1 = \frac{20}{60} = \frac{1}{3}$$
   $$I_G(Q_R) = 1 - \left( \frac{4}{9} + \frac{1}{9} \right) = 1 - \frac{5}{9} = \frac{4}{9} \approx 0.4444$$
4. **Взвешенная неоднородность после разбиения:**
   $$I_G(Split) = \frac{40}{100} \cdot 0.0 + \frac{60}{100} \cdot \frac{4}{9} = 0.6 \cdot 0.4444 \approx 0.2667$$
5. **Прирост информации (Gini Gain):**
   $$\Delta I_G = 0.32 - 0.2667 = 0.0533 > 0$$
   **Вывод:** Неоднородность снизилась, разбиение эффективно.

## ✍️ Задача 3. Ручной прогноз в Наивном Байесовском классификаторе

### Условие:
Дана априорная вероятность: $P(Y=0) = 0.8$, $P(Y=1) = 0.2$.  
Для нового объекта с двумя бинарными признаками $x_1=1, x_2=0$ известны условные правдоподобия:
* При $Y=0$: $P(x_1=1|Y=0) = 0.5$, $P(x_2=0|Y=0) = 0.7$;
* При $Y=1$: $P(x_1=1|Y=1) = 0.8$, $P(x_2=0|Y=1) = 0.9$.
К какому классу Наивный Байес отнесет объект?

### Решение:
1. **Вычисляем пропорциональную апостериорную оценку для класса 0:**
   $$\text{Score}(Y=0) = P(Y=0) \cdot P(x_1=1|Y=0) \cdot P(x_2=0|Y=0) = 0.8 \cdot 0.5 \cdot 0.7 = 0.28$$
2. **Вычисляем оценку для класса 1:**
   $$\text{Score}(Y=1) = P(Y=1) \cdot P(x_1=1|Y=1) \cdot P(x_2=0|Y=1) = 0.2 \cdot 0.8 \cdot 0.9 = 0.144$$
3. **Нормировка (апостериорные вероятности):**
   $$P(Y=0 | \mathbf{x}) = \frac{0.28}{0.28 + 0.144} = \frac{0.28}{0.424} \approx 0.6604 \quad (66.04\%)$$
   $$P(Y=1 | \mathbf{x}) = \frac{0.144}{0.424} \approx 0.3396 \quad (33.96\%)$$
**Ответ:** Объект относится к **классу 0** ($66.04\% > 33.96\%$).

## ✍️ Задача 4. Расчет расстояний для $k$-NN

### Условие:
Точка запроса: $q = (2, 5)$.  
Два соседа: $A = (1, 2)$ и $B = (4, 7)$.  
Какой сосед ближе по Евклидову расстоянию ($L_2$) и по Манхэттенскому ($L_1$)?

### Решение:
1. **Евклидово расстояние ($p=2$):**
   $$d_{L_2}(q, A) = \sqrt{(2 - 1)^2 + (5 - 2)^2} = \sqrt{1^2 + 3^2} = \sqrt{10} \approx 3.162$$
   $$d_{L_2}(q, B) = \sqrt{(2 - 4)^2 + (5 - 7)^2} = \sqrt{(-2)^2 + (-2)^2} = \sqrt{8} \approx 2.828$$
   * По Евклиду: **Точка $B$ ближе** ($\sqrt{8} < \sqrt{10}$).
2. **Манхэттенское расстояние ($p=1$):**
   $$d_{L_1}(q, A) = |2 - 1| + |5 - 2| = 1 + 3 = 4$$
   $$d_{L_1}(q, B) = |2 - 4| + |5 - 7| = 2 + 2 = 4$$
   * По Манхэттену: **Расстояния строго равны** ($4 = 4$).

## ✍️ Задача 5. Порог классификации (Threshold Moving)

### Вопрос преподавателя:
«Что произойдет с метриками $Precision$ и $Recall$, если мы сдвинем порог отсечения вероятности $\theta$ с $0.5$ до $0.8$?»

### Ответ:
* Порог стал жестче: теперь для предсказания класса 1 модель требует уверенности $\ge 80\%$.
* **Число предсказанных положительных примеров ($\hat{y} = 1$) резко уменьшится.**
* **$Precision$ (Точность) вырастет:** среди оставшихся срабатываний будет значительно меньше ложных тревог ($FP \downarrow$).
* **$Recall$ (Полнота) упадет:** мы пропустим много реальных уходящих клиентов с вероятностями от $0.5$ до $0.79$ ($FN \uparrow$).
