# Лабораторная работа №2: Классификация. Нейронные сети

## Описание работы
**Цель работы:** изучение методов классификации данных, реализованных в библиотеке Scikit-Learn, а также ознакомление с нейронными сетями с использованием библиотек TensorFlow и TensorBoard.

---

## Постановка задачи
Необходимо выбрать и подготовить датасет для классификации, затем построить классификационные модели с помощью пяти методов:
1. **Наивный Байесовский классификатор** (`GaussianNB`, `MultinomialNB`, `ComplementNB`, `BernoulliNB`);
2. **Деревья решений** (`DecisionTreeClassifier`);
3. **Линейный дискриминантный анализ** (`LinearDiscriminantAnalysis`);
4. **Метод опорных векторов** (`Support Vector Machines` / `SVC`);
5. **Метод ближайших соседей** (`k-Nearest Neighbors` / `KNeighborsClassifier`).

Затем сравните качество работы классификаторов с помощью следующих метрик:
- **Accuracy** (точность);
- **Precision** (доля правильно классифицированных положительных примеров);
- **Recall** (чувствительность, доля верно найденных положительных примеров);
- **F1-Score** (среднее гармоническое precision и recall);
- **Площадь под кривой ROC (AUC-ROC)**.

Настройте гиперпараметры каждого метода и проведите исследование влияния различных параметров на качество классификации.

Реализуйте и протестируйте **нейронную сеть на TensorFlow**, исследуйте эффект настройки гиперпараметров и визуализируйте процесс обучения с помощью инструмента **TensorBoard**.

---

## Содержание отчета
1. **Введение:** описание целей и задач лабораторной работы.
2. **Выбор и подготовка датасета:** информация о выбранном датасете, характеристика признаков и целей, предобработка данных.
3. **Разбиение выборки:** разбиение данных на обучающий и тестовый наборы.
4. **Методы классификации:** описание методов классификации.
5. **Настройка гиперпараметров:** детали проведенных экспериментов по изменению параметров каждого метода и оценка влияния этих изменений на качество классификации.
6. **Нейронная сеть на TensorFlow:** описание архитектуры нейронной сети, используемых слоев, функций активации, потерь и оптимизатора; эксперименты с изменением гиперпараметров (число эпох, размеры батчей, количество слоев и нейронов, функции активации); графики обучения и валидации; мониторинг обучения через TensorBoard.
7. **Сравнительный анализ:** таблица сравнения метрик качества для всех рассмотренных методов классификации и аргументированный вывод о лучшем подходе для данного датасета.
8. **Заключение.**

## Рекомендации по выполнению
1. Используйте библиотеки **Pandas** и **NumPy** для обработки данных, **Scikit-Learn** для методов классификации и **TensorFlow/Keras** для построения нейронной сети.
2. Перед началом работы убедитесь, что ваши данные очищены и обработаны должным образом (заполнение пропусков, нормализации и стандартизации).
3. Для разбивки данных используйте функцию `train_test_split()` из Scikit-Learn.
4. Зафиксируйте случайно генерируемые числа (`seed` / `random_state`), чтобы эксперименты были воспроизводимыми.
5. Визуализируйте результаты классификации с помощью графика ROC-кривых и столбчатых диаграмм для каждой из метрик (accuracy, precision, recall, F1-score).
6. Для эксперимента с TensorFlow используйте средства визуализации **TensorBoard**, чтобы следить за прогрессом обучения (loss, accuracy, validation loss, validation accuracy).
7. Варьируя параметры, старайтесь зафиксировать, как изменяется качество модели.
